# Utsavkosh

## Project Overview
Utsavkosh is a web-based management application designed for wedding and event decoration businesses. It helps manage customer information, enquiries, event bookings, decoration packages, inventory items, and invoices in one place.

## Problem Addressed
Many wedding and event decoration businesses rely on manual diaries, paper records, and phone calls to manage customer details, bookings, inventory, and payments. These methods can make information difficult to organize and track. Utsavkosh aims to simplify these activities through a centralized digital application.

## Features
- User authentication using email and password, with Google login.
- Customer and enquiry management.
- Event booking management.
- Decoration package and inventory management.
- Invoice creation and total calculation.
- Web-based access to the application.

## Technologies Used
- **Frontend:** React and TypeScript
- **Backend and Database Services:** Supabase
- **Hosting and Deployment:** Netlify
- **Version Control:** Git and GitHub

## Installation and Setup

### Prerequisites
- Node.js and npm
- Git

### Steps
1. Clone the repository:

   `git clone https://github.com/notraghavv/Utsavkosh-V1.git`

2. Navigate to the project directory:

   `cd Utsavkosh-V1`

3. Install the project dependencies using the package manager and lockfile provided in the repository.

4. Configure the required Supabase project settings and environment variables according to the application's configuration. Do not commit credentials, API keys, passwords, or other secrets.

5. Start the development server using the appropriate script defined in `package.json`, commonly:

   `npm run dev`

6. Open the local URL displayed in the terminal to access the application.

**Note:** The exact setup commands and environment variable names should be confirmed against the current project configuration.
